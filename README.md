# statistical-analysis-prompts-responses
## Структура prompts.csv

Файл `prompts.csv` содержит следующие поля:

`prompt_id` — уникальный идентификатор промпта. Используется для связи промпта с ответами моделей.

`category` — техническое название категории задачи. Например: `code_generation`, `bug_fixing`, `algorithm_explanation`, `testing`.

`category_label` — человекочитаемое название категории задачи. Например: `Генерация кода`, `Исправление ошибок`.

`length_level` — требуемая длина ответа: `short`, `medium`, `long`.

`has_context` — признак наличия контекста в промпте: `1` — контекст есть, `0` — контекста нет.

`has_constraints` — признак наличия ограничений в промпте: `1` — ограничения есть, `0` — ограничений нет.

`role` — техническое название роли, заданной в промпте. Например: `none`, `python_developer`, `qa_engineer`, `computer_science_teacher`.

`role_text` — текстовое описание роли, добавленное в промпт. Например: `Ты Python-разработчик.`

`context_text` — текст контекста, добавленный в промпт. Если контекст не использовался, поле пустое.

`constraints_text` — текст ограничений, добавленный в промпт. Если ограничения не использовались, поле пустое.

`template_text` — исходный шаблон промпта до подстановки переменных.

`variable_values` — значения переменных, подставленные в шаблон промпта. Хранятся в формате JSON.

`expected_response_type` — ожидаемый тип ответа модели. Например: `code`, `code_and_text`, `text`, `structured_text`, `tests`, `test_cases`.

`prompt_text` — полный итоговый текст промпта, который передается нейросетевой модели.

`char_count` — количество символов в итоговом тексте промпта.

`word_count` — количество слов в итоговом тексте промпта.

`sentence_count` — количество предложений в итоговом тексте промпта.

`prompt_line_count` — количество непустых строк в промпте.

`prompt_paragraph_count` — количество абзацев в промпте.

`has_question_form` — признак вопросительной формы: `1` — в промпте есть знак вопроса, `0` — нет.

`has_role` — признак наличия роли: `1` — роль задана, `0` — роль отсутствует или равна `none`.

`has_format_instruction` — признак наличия инструкции по формату ответа: `1` — инструкция есть, `0` — инструкции нет.

`has_code_in_prompt` — признак наличия кода в тексте промпта: `1` — код обнаружен, `0` — код не обнаружен.

`constraint_count` — количество найденных ограничений в промпте. Учитывает блок ограничений и ключевые ограничивающие фразы.

`instruction_count` — количество инструктивных конструкций в промпте. Например: `напиши`, `реализуй`, `исправь`, `объясни`, `составь`.

`directive_words_count` — количество директивных слов в промпте. Показывает, насколько явно промпт задает действие для модели.

`technical_terms_count` — количество технических терминов в промпте. Например: `Python`, `код`, `функция`, `алгоритм`, `JSON`, `тест`.

`structure_score` — интегральная оценка структурированности промпта от `0` до `1`. Учитывает абзацы, строки, списки, контекст, ограничения и явные инструкции.

`specificity_score` — интегральная оценка конкретности промпта от `0` до `1`. Учитывает наличие контекста, ограничений, формата ответа, технических терминов, кода и директивных слов.

`created_at` — дата и время создания промпта в формате ISO.
